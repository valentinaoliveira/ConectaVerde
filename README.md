# Conecta Verde 🌱

**Cartilha digital interativa sobre lógica, algoritmos e sustentabilidade digital.**

Projeto desenvolvido para a atividade de extensão do curso de **Ciência da Computação da UNIP**, com o objetivo de tornar conceitos de tecnologia mais acessíveis à comunidade.

## Funcionalidades

- **4 capítulos educativos** sobre tecnologia, sustentabilidade e pensamento computacional.
- **3 atividades práticas:** Robô dos Algoritmos, Destino Correto e Complete o Algoritmo.
- **Quiz interativo** com 8 questões e correção automática.
- **Acompanhamento do progresso** dos capítulos no navegador.
- **Layout responsivo** para celular, tablet e computador.
- **Avaliação pelo Google Forms** integrada ao site.

## Tecnologias

HTML5 · CSS3 · JavaScript (sem frameworks)

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor.
